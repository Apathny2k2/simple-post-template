# Brief: take the AI voice out of Vellum (studio and plugin)

For the agent picking this up. Written 2026-09-28 by the session that
started the audit. Repo `Apathny2k2/simple-post-template`, branch
`claude/blockbench-react-editor-lk38qe`, draft PR #3.

## 1. The job

The operator wants everything that reads as AI-generated removed from the
studio and the plugin: UI copy, code comments, docs, class and token names,
and the colour scheme. Replace it with plain writing and plain names. Add
some humour in a few places, mainly by upgrading the studio's loading
states with fun, on-theme animations.

You will produce:

1. `AUDIT.md` at the repo root. One row per finding: ID, severity, file and
   line, current text, proposed text, status. Scanner totals before and
   after each phase.
2. The fixes, one phase per commit, pushed and republished as you go.
3. A short report to the operator after each phase (see §8).

Severity: **S1** says something untrue or describes code that is gone.
**S2** is text a user reads. **S3** is a comment. **S4** is a name.

  `vellum/dist/vellum.html` to
  `https://claude.ai/artifact/BZpDzWLJ4z6soEAmVMcVwN`. Pass `url`, omit

### Phase 0. Measure

Write `vellum/scripts/slop-scan.mjs` so every later phase has numbers.

- Walk `vellum/src` (`.ts`, `.tsx`, `.css`) and the repo's `.md` files.
  Skip `node_modules` and code fences.
- Separate comments from strings properly. Use the installed `typescript`
  package (6.0.3). Parse with `ts.createSourceFile`. Collect comments with
  `ts.getLeadingCommentRanges` and `ts.getTrailingCommentRanges` at each
  node, deduped by start offset. Collect copy from `StringLiteral`,
  `NoSubstitutionTemplateLiteral`, template heads and spans, and `JsxText`.
  Don't run the raw `ts.createScanner` over TSX: an apostrophe in JSX text
  looks like the start of a string. CSS only has `/* */` comments, so a
  regex is fine there.
- Only count prose-like strings: 3 or more words, starting with a letter.
  Skip `className` values, imports and paths.
- Per file: comment lines, code lines, ratio, banner blocks, longest
  comment block, hits per rule. Totals at the end. `--json` for machine
  output, `--md` for tables to paste into `AUDIT.md`.
- Starting rules (add more as you find them):
  - antithesis: `, not `, `not a X but`, `rather than`
  - the-one: `the one|only (thing|place|surface|control|number|...)`
  - moral: `An? X is (not )?an? Y.`
  - history: `used to`, `no longer`, `any more`, `It was`, `Was X`
  - shouting: 4 or more capitalised words in a row
  - stock words: `load-bearing`, `footgun`, `deliberately`, `on purpose`,
    `by design`, `quietly`, `silently`, `simply`, `honest`
  - numbered framing: `Two|Three|Four (things|details|notes|rules|traps|...)`
  - unmeasured counts: `~\d+ call sites`
  - dash asides: ` - ` and ` — ` inside sentences
  - marketing words: seamless, robust, leverage, delve, elevate, empower,
    effortless, crucial, comprehensive, streamline, unlock, harness
  - emoji
- Print a line saying these are candidates for a person to judge.

Rough baseline from grep (the scanner will be more exact): about 1,800
comment lines across 68 files, 167 banner comments. Heaviest by comment
lines: `lib/config.ts` 175, `pages/Editor.tsx` 162, `lib/world.ts` 121,
`lib/vellum.ts` 116, `lib/model.ts` 91, `lib/dash.ts` 82, `lib/mcmodel.ts`

### Phase 2. Loading animations and humour

The operator asked for this directly, and it's the most visible part, so
do it early.

Where the studio waits today:

- Boot. `#root` is empty until the bundle runs.
  `vellum/scripts/bundle-single-file.mjs:95` hardcodes
  `<div id="root"></div>`, so anything placed inside `#root` in
  `index.html` is dropped from the single-file build.
- `pages/Support.tsx:92`: the ticket list shows the word "Loading…".
- `pages/Support.tsx:356-366`, with `@keyframes dot` in `Support.css`:
  three generic bouncing dots while the agent is typing.
- Busy buttons: `pages/Settings.tsx:189` "Sending…", `Settings.tsx:318`
  "Checking", `pages/Support.tsx:480` "Opening…",
  `components/ReloadControl.tsx:52` "Applying…".

Build:

- A `Loader` component in three sizes: inline (about 14px, in buttons),
  block (about 48px, lists and panels) and hero (about 96px, boot).
- Keep it Minecraft-flavoured and drawn in fine 1px lines to match the
  current look. One idea that fits: an isometric block draws its edges,
  fills its faces with Minecraft's fixed face shading (top 100%, left 80%,
  right 60%), cracks as if being mined, pops into a few particles, and
  builds again. For the inline size, a small cube that bobs like a dropped
  item, swapping its left and right face shades to fake a spin. Other
  on-theme ideas are welcome.
- Typing indicator: three small blocks placed one after another instead of
  bouncing dots.
- Boot screen: markup plus its own small `<style>` inside `#root` in
  `index.html`, so React's first render replaces it. Change the bundler to
  copy the contents of `#root` from `dist/index.html` instead of
  hardcoding an empty div (for example
  `/<div id="root">([\s\S]*)<\/div>\s*<\/body>/`). Use HTML entities, not
  raw non-ASCII, because `--fragment` output has no charset. No external
  assets: the bundler fails the build on any absolute `src` or `href`.
  Fade it in after about 150ms so fast loads don't flash.
- Quips: one short line under block and hero loaders. Change it once per
  animation loop, starting at a random line. Starters in Appendix A.

Accessibility (required):

- The loader has `role="status"` and a plain label such as "Loading
  tickets". The quip and the SVG are `aria-hidden="true"`, so screen
  readers announce the label once and skip the quips.
- `base.css` cuts animations to almost nothing under
  `prefers-reduced-motion`. Make the un-animated state a complete shaded
  block with no cracks or particles, and don't rotate quips for those
  users (check `matchMedia`).
- Busy buttons keep their text ("Sending…"). The animation is extra.

Humour rules:

- Jokes are extra. The plain label always says what is happening.
- No jokes where someone may have lost work, money or data: crash details,
  billing, destructive confirmations, failed saves.
- Keep it about Minecraft and modelling. Dry, under about 8 words. No
  emoji, no "Oops!", no exclamation marks.
- Beyond the loaders: the 404 page (`App.tsx:20-24`) and the crash screen
  title (`components/ErrorBoundary.tsx:42`), keeping the line that saved
  files are safe. List other candidates in `AUDIT.md` and ask before adding
  more.

Done when: screenshots of every loader state, one with reduced motion
(`page.emulateMedia({ reducedMotion: 'reduce' })`), zero page errors, and
`contrast-audit.mjs` still at 0 on all five routes.
