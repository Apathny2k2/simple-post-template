# Working notes for this repository

## Vellum

The app lives in `vellum/`. Vite 8 + React 19 + TypeScript, pnpm, no UI
framework. `vellum/README.md` is the design record — read it before
changing how a subsystem works.

### Publish the artifact on every push

The user reads the app through a published artifact, not through this
repository. **Every push must be followed by a republish**, or they are
looking at a stale build while commits go by.

```
cd vellum && pnpm build:single      # writes dist/vellum.html
```

Then publish `vellum/dist/vellum.html` to the existing artifact:

- URL: `https://claude.ai/artifact/BZpDzWLJ4z6soEAmVMcVwN`
- Pass `url` so it updates in place rather than creating a second one.
- Omit `capabilities` — omitting carries the existing ones forward.
- Omit `icon` so the artifact keeps the one it has.

### Typechecking

`tsc --noEmit` is a **silent no-op** here: the root `tsconfig.json` is a
project-reference stub with `files: []`, so it typechecks nothing and
exits 0. Use `tsc -b` (which is what `pnpm build` runs).

### The sample models

`vellum/src/models/*.vellum` are generated, not hand-written. They are
built by `vellum/scripts/make-samples.mjs`, which drives a real browser
so the codec, the UV packer and the canvas the sheets are painted on are
the app's own. To change one, edit its spec in that script and re-run it
against a dev server:

```
cd vellum && pnpm dev                                   # one terminal
PLAYWRIGHT_CHROMIUM=/opt/pw-browsers/chromium \
  VELLUM_DEV=http://localhost:5173 node scripts/make-samples.mjs
```

`voidling.vellum` and `resonator_block.vellum` predate that script and
are not regenerated by it.

### Browser verification

Chromium is at `/opt/pw-browsers/chromium`; do not run
`playwright install`. Launch with
`chromium.launch({ executablePath: '/opt/pw-browsers/chromium', args: ['--no-sandbox'] })`.

A caveat that has cost time twice: after a hot update Vite serves the
changed module at a `?t=` URL, so a test's dynamic
`import('/src/lib/x.ts')` gets a **second** module instance that
disagrees with the page. Hard-reload before importing app modules from a
test.

### Minecraft conventions the app encodes

16 units = 1 block. An item is rendered in a 16-unit slot. Face shading
is fixed and directional: top 1.0, north/south 0.8, east/west 0.6,
bottom 0.5. Textures are one texel per unit.
